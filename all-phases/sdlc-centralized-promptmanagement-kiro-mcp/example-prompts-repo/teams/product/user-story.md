# User Story Creation Prompt

**Team**: Product  
**Purpose**: Generate well-structured user stories  
**Usage**: `/prompt product-user-story`

## Template

Help me create a user story for {{feature_name}}.

### User Story Format
**As a** {{user_type}}  
**I want** {{functionality}}  
**So that** {{benefit}}

### Acceptance Criteria
Please define clear acceptance criteria using the Given-When-Then format:

**Given** [initial context/state]  
**When** [action is performed]  
**Then** [expected outcome]

### Definition of Done
- [ ] Functional requirements met
- [ ] UI/UX design approved
- [ ] Accessibility standards followed
- [ ] Tests written and passing
- [ ] Documentation updated

### Story Quality Check
Ensure the story is:
1. **Specific** - Clear and unambiguous
2. **Measurable** - Success criteria defined
3. **Achievable** - Realistic scope
4. **Relevant** - Aligned with business goals
5. **Time-bound** - Clear delivery expectations
