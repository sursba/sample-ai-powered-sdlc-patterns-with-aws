# UI Design Review Prompt

**Team**: Design  
**Purpose**: UI/UX review guidelines  
**Usage**: `/prompt design-ui-review`

## Template

Please conduct a UI/UX review for {{feature_name}}.

### Visual Design
- **Consistency**: Does it follow our design system?
- **Typography**: Appropriate font choices and hierarchy
- **Color**: Brand compliance and contrast ratios
- **Spacing**: Consistent margins and padding

### User Experience
- **Navigation**: Intuitive flow and clear pathways
- **Interaction**: Appropriate feedback and micro-interactions
- **Information Architecture**: Logical content organization
- **Error States**: Clear error messages and recovery paths

### Accessibility (WCAG 2.1 AA)
- [ ] Color contrast meets minimum ratios (4.5:1 for normal text)
- [ ] Keyboard navigation support
- [ ] Screen reader compatibility
- [ ] Focus indicators visible
- [ ] Alternative text for images

### Responsive Design
- Mobile-first approach
- Touch target sizes (minimum 44px)
- Content reflow and readability

Please provide specific, actionable feedback with priority levels (High/Medium/Low).
