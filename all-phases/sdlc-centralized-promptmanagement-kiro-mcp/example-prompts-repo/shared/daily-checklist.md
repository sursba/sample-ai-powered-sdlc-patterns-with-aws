# Daily Developer Checklist

**Team**: Shared  
**Purpose**: Quick daily checklist for developers to start their day  
**Usage**: `/prompt daily-checklist`

## Template

Please help me review my daily developer checklist:

### Morning Routine
- [ ] Check email and Slack for urgent messages
- [ ] Review calendar for meetings
- [ ] Check CI/CD pipeline status
- [ ] Review any open PRs assigned to me

### Code Hygiene
- [ ] Pull latest changes from main branch
- [ ] Check for any failing tests
- [ ] Review yesterday's commits for any follow-ups

### Planning
- [ ] Review today's sprint tasks
- [ ] Identify any blockers
- [ ] Update task status in project board

What should I prioritize today based on this checklist?
