# Sprint Retrospective

**Team**: Shared  
**Purpose**: Facilitate structured sprint retrospectives with actionable outcomes  
**Usage**: `/prompt retrospective`

## Template

Please help facilitate a sprint retrospective:

**Sprint**: {{sprint_name}}
**Team**: {{team_name}}

{{#if sprint_goal}}
**Sprint Goal**: {{sprint_goal}}
{{/if}}

Generate a retrospective discussion guide covering:

### What Went Well
- Celebrate successes and wins
- Identify practices to continue

### What Could Be Improved
- Areas for growth
- Process bottlenecks identified

### Action Items
- Specific, assignable improvements
- Timeline for implementation

### Team Health Check
- Collaboration quality
- Communication effectiveness
- Work-life balance observations
